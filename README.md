# HTML & CSS Learning

This repository is for learning HTML and CSS fundamentals for frontend web development.

## Goals
- Learn how webpages are built
- Understand HTML structure
- Learn CSS styling and layouts
- Build responsive web pages
- Prepare for React frontend development

## Topics Covered
- HTML basics
- Headings and paragraphs
- Links and images
- Forms and buttons
- CSS colors and spacing
- Flexbox and Grid
- Responsive design

## Purpose
This repository helps build frontend development skills needed for modern web applications and developer platforms.
